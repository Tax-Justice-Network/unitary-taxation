Loss-consolidation sensitivity (CbCR static approximation): credits ZERO tax on reported losses in the apportionment (a loss pays no tax, not a refund). This is a PARTIAL, STATIC, CbCR-aggregate view of the loss-consolidation effect; it differs from the proper firm-level estimate (WIFO 2026), which is dynamic (models loss carry-forward across years) and group-level (captures losses netted inside net-positive cells). This measure (a) misses losses hidden inside net-positive aggregate cells and (b) ignores carry-forward value, so it is an UPPER BOUND on the permanent effect; the gap to the headline is largely transitory. ADDITIONAL estimate — NOT the main specification. Exact for inf-threshold specs; approximate for 15%-haven-gated specs (negative side is rescaled in adjust_misalignment).
