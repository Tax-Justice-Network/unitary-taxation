# Resource-correction datasets — what's in each

A plain-language guide to the datasets used to remove resource-sector activity from
CbCR before the unitary-taxation analysis. Money values are USD unless noted.

## Inputs (where the resource numbers come from)

**`data/intermediate/extractive/eiti_company_payments_long.csv`** — the EITI payments data.
One row per **company × source country × year × revenue stream**. Shows, for each extractive
company, what it paid the government, classified into royalties (pre-profit) / income tax
(post-profit) / state dividends (equity) / other. Pulled from the **EITI Open Data API**
(58 countries, back to 1999, ~$2.84tn). This is the most granular, most reliable input — it is
genuinely bilateral once companies are matched to their owner.

**`data/intermediate/extractive/eiti_company_hq_map.csv`** — the company→owner map. One row per
EITI company; shows the matched Orbis entity and its **ultimate-owner (HQ) country** (`hq_iso3`),
the match score/method, and whether the group is in the CbCR ≥€750M universe. This is what turns
each EITI payment into a home-country/host-country pair.

**`data/raw/eiti_xlsx_production.csv`** — EITI **production volumes** (not payments). Parsed from
the country EITI Summary-Data Excel workbooks in `data/raw/EITI reports/` by
`1_5_parse_eiti_xlsx.py`. One row per iso3 × year × commodity × measure. Feeds the rents
calibration (used for the floored scenario), so the Excel files must be kept.

**`data/raw/EITI reports/<Country>/*.xlsx`** — the raw EITI Summary-Data workbooks. Used **only**
for production volumes now (payments come from the API). Kept because the production path
(`1_5 → 2_7 → rents`) depends on them.

**`data/intermediate/extractive/extractive_royalty_dataset_yearly.csv`** — the GRD layer. The
UNU-WIDER Government Revenue Dataset resource revenue (a single national total per country-year,
no company detail) plus World Bank resource rents per commodity. Used for countries **not part of
EITI**; the national total is split across owner countries using Orbis ownership shares.

**`data/raw/resources/resource_profit_tax_rate.csv`** and **`data/final/effective_resource_cit_rates.csv`**
— resource tax rates. The first gives the income-tax-based resource profit-tax rate per
(country, commodity) with a source note; the second gives a `combined_effective_rate`
(headline CIT + resource surtax) per country. The rate converts a known resource tax into the
resource profit behind it (`profit = tax / rate`).

**`data/raw/resources/manual_resource_revenue.csv`** — figures set by hand for a few large producers not in
EITI (e.g. Gulf states), from company filings/prospectuses, IMF Article IV, and national budgets;
each with a source note and a pre/post/equity split.

## The consolidated control table

**`data/raw/resources/resource_country_parameters.csv`** — the single source of truth, one row per resource
country. Shows whether the country is **included** in the correction (and the `drop_reason` if
not), the resource **rate** and its **source**, the **domestic-vs-foreign split** and its
**source**, the extractive rents % of GDP, the data source(s) used, and a `status`/confidence
flag. Non-resource economies (rent-proxy-only, extractive rents < 1% of GDP, forest excluded) are
marked `include = no`.

## The assembled panel

**`data/intermediate/extractive/resource_payments_by_hq_source_yearly.csv`** — the assembled
resource take. One row per **source country × HQ country × commodity × year**, with the take split
into `pre_profit_payments_usd` (royalties), `post_profit_payments_usd` (income tax),
`equity_income_usd` (state dividends), and a `data_source` tag (eiti / manual / grd / rent_proxy).
This is what script 4 adds back to / removes from CbCR.

## Outputs (the corrected datasets)

**`data/final/cbcr_main_excl_resource.csv`** — CbCR with resource profit and resource tax removed
(the non-resource corporate income that enters the UT). Ships with the recomputed non-resource
ETR family.

**`data/final/cbcr_main_incl_resource.csv`** — CbCR grossed up by pre-profit royalties (the
"resources included" view); carries `actual_resource_contribution_usd` (pre + post + equity) for
comparing UT yield to the actual state take.

**`data/final/cbcr_main_excl_resource_floored.csv`** — as excl_resource, but with the IGF-ATAF
minimum-royalty floor enforced (extra royalty removed from the UT pool on top of the resource
profit; `floor_add_on_*` records the gap).

## Review / QA

**`data/raw/country_resource_info/<ISO3>.txt`** — one human-readable sheet per resource country:
which resources, how the state taxes them (rate + capture split, with sources), the year-by-year
correction (reported → removed → non-resource), domestic vs foreign, plausibility flags, and a
glossary. Generated by `country_resource_info.py`.
